# Library Management System

A console-based Library Management System developed in C++ using Object-Oriented Programming and File Handling concepts. The application helps manage books, members, and issue/return records efficiently through a menu-driven interface.

## Features

* Add new books
* Display all books
* Search books by title or author
* Update book details
* Delete books
* Add new members
* Display all members
* Search members
* Update member details
* Delete members
* Issue books to members
* Return issued books
* View issue records
* Persistent data storage using text files
* Input validation and error handling

## Technologies Used

* C++
