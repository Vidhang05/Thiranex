# Mini Game Project

## Description

This project is a console-based Mini Game Hub developed in C++ using object-oriented programming concepts. It includes two interactive games: Tic Tac Toe and Snake Game.

The project demonstrates practical implementation of classes, inheritance, polymorphism, loops, arrays, conditional statements, and dynamic game logic.

## Features

Dynamic game board display

Two playable games:
Tic Tac Toe
Snake Game

Win and loss detection

Replay option

Interactive menu-driven interface

Object-oriented design

Real-time keyboard controls

## Technologies Used

Object-Oriented Programming
